# Joseph Stalin — AI & Data Science Portfolio

Interactive personal portfolio exploring AI, Data Science, software development, and cybersecurity.

## Structure

- `index.html` — page structure and content
- `css/style.css` — all styles and responsive design
- `js/script.js` — interactions and animations
- `assets/images/` — future images
- `assets/certificates/` — future certificates

Designed to work as a static GitHub Pages site.
